    Change the workbench Cursor changes this page, its server and their tests (tools/agent)
    
  
    
    Say what should be different in the workbench. Cursor changes tools/agent/ only --
    never policy.json, which says what each run may change. It runs only while
    nothing else runs, and nothing else starts until it has finished. Before you review it, the
    change must pass the workbench checks: the Python compiles, the page parses, the workbench's
    tests and the page checks pass. It then waits on the Commit and push tab under its own job
    (Review it opens it). After Approve & push, Stop and Start the workbench to
    run the changed server. If the page itself stops working, put everything back from a terminal:
    python tools/agent/loop.py discard --job <the workbench job>.
